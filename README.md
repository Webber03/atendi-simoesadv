# Painel CRM - Simões Advogados

Instância dedicada do CRM Whitelabel para a empresa **Simões Advogados**.

## 🚀 Como Executar Localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Verifique o arquivo `.env` com as credenciais do banco PostgreSQL.

3. Inicie o servidor:
   ```bash
   npm start
   ```
   Acesse: `http://localhost:3003`

Consulte o arquivo [SIMOES_ADV_MEMORIA_PROJETO.md](./SIMOES_ADV_MEMORIA_PROJETO.md) para detalhes de banco de dados, deploy e integração Google Drive.
